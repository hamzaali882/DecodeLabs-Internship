# Project 3: SQL Data Analysis

## Overview

This project focuses on performing SQL-based data analysis on an e-commerce orders dataset. The objective is to extract meaningful business insights using SQL queries and demonstrate fundamental database querying skills.

## Project Objectives

* Analyze order data using SQL.
* Retrieve, filter, and sort records efficiently.
* Perform aggregations to calculate business metrics.
* Group data to identify trends and patterns.
* Generate insights from transactional data.

## Dataset Information

The dataset contains e-commerce order records with the following attributes:

* Order ID
* Date
* Customer ID
* Product
* Quantity
* Unit Price
* Shipping Address
* Payment Method
* Order Status
* Tracking Number
* Items in Cart
* Coupon Code
* Referral Source
* Total Price

* Oracle SQL Developer
* SQL

* SELECT

* COUNT()
* SUM()
* AVG()
* HAVING

## Analysis Performed

### Data Retrieval

* Displayed all records from the dataset.
* Selected specific columns for focused analysis.

### Filtering and Sorting

* Retrieved orders above a specific price threshold.
* Filtered delivered orders.
* Sorted orders by highest and lowest revenue.

### Aggregation Analysis

* Calculated total number of orders.
* Calculated total revenue.
* Computed average order value.

### Product Analysis

* Counted orders by product.
* Calculated revenue generated by each product.
* Determined average revenue per product.

### Customer Analysis

* Identified customers with high spending.
* Listed top spending customers.

### Payment and Status Analysis

* Analyzed order distribution by payment method.
* Analyzed order distribution by status.

### Marketing Analysis

* Evaluated revenue generated through referral sources.
* Analyzed coupon code usage.

## Key Insights

* SQL aggregation functions help summarize large datasets efficiently.
* Product-level analysis highlights best-performing products.
* Customer spending analysis identifies valuable customers.
* Referral source analysis provides marketing performance insights.
* Order status tracking helps monitor operational performance.
