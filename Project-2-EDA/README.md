# Project 2 - Exploratory Data Analysis (EDA)

## Overview

This project focuses on Exploratory Data Analysis (EDA) of an e-commerce dataset. The objective is to understand the dataset, identify patterns and trends, detect outliers, and generate meaningful business insights using descriptive statistics and data analysis techniques.

## Objectives

* Analyze dataset structure and contents
* Calculate descriptive statistics (mean, median, count, etc.)
* Identify trends and patterns in customer orders
* Detect outliers and unusual transactions
* Generate business insights from the data

## Dataset Information

The dataset contains e-commerce order records with information about:

* Orders
* Customers
* Products
* Payment Methods
* Order Status
* Referral Sources
* Revenue and Pricing

## Tools and Technologies

* Python
* Pandas
* NumPy
* Matplotlib
* Jupyter Notebook
* Microsoft Excel

## Analysis Performed

### 1. Data Inspection

* Reviewed dataset structure
* Checked data types
* Identified missing values

### 2. Descriptive Statistics

Calculated:

* Mean
* Median
* Minimum Values
* Maximum Values
* Record Counts

### 3. Missing Value Analysis

* Examined missing data across all columns
* Identified missing coupon code records

### 4. Product Analysis

* Determined most frequently ordered products
* Compared product demand

### 5. Payment Method Analysis

* Analyzed customer payment preferences

### 6. Referral Source Analysis

* Evaluated marketing channel performance

### 7. Trend Analysis

* Examined order and revenue trends over time

### 8. Outlier Detection

* Identified unusually high-value transactions
* Investigated extreme order values

## Key Findings

* Average order value exceeded 1000 currency units.
* Printer was the most frequently purchased product.
* Instagram generated the highest number of referrals.
* Online payment was the most used payment method.
* Revenue and order volume showed a declining trend over the observed period.
* Only a small number of transactions were classified as outliers.
