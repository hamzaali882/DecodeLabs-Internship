# Data Analytics Portfolio

This repository contains my Data Analytics projects completed during the DecodeLabs Industrial Training Program. The projects focus on data cleaning, exploratory data analysis, and SQL-based data analysis using real-world datasets and industry-standard tools.

## Projects

**Objective:** Clean and prepare raw datasets for analysis.

**Skills Demonstrated:**

* Handling Missing Values
* Removing Duplicates
* Data Formatting
* Data Preparation

**Tools Used:**

* Microsoft Excel
* Data Analysis Techniques

### Project 2: Exploratory Data Analysis (EDA)

**Objective:** Explore and analyze datasets to identify trends, patterns, and insights.

**Skills Demonstrated:**

* Descriptive Statistics
* Data Visualization
* Trend Analysis

* Business Insights Generation

**Tools Used:**

* Microsoft Excel

**Skills Demonstrated:**
